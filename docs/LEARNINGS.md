# Learnings

## Entries

- 2026-11-06: Resumen cards stacked one letter per line and Ver ajustes stopped taking clicks — `lg:` counts the whole window, the sidebar already takes ~250px, and the figure had `min-w-0` beside a `shrink-0` sub — size that grid with `auto-fit` / `minmax(16rem)`, keep the figure `whitespace-nowrap`, and put Margen and Ajustado under it.
- 2026-11-06: the admin adjustment dialog stayed full width after `max-w-sm` — `.shell-content .w-full` sets `max-width: 100%` and beats a single utility — do not put `w-full` on a dialog inside the shell; set the width in style and portal it to `document.body`.
- 2026-11-06: a ~100 KB EBITDA justification showed "hasta 8 MB" — Workers have no persistent disk, the write failed, and every failure used the size sentence — store the bytes in Postgres (`adjustment_document`), and use a separate sentence for type, size, and save.
- 2026-11-06: `npx vinext-cloudflare deploy` aborted with "remove the `--strict` flag" after a successful build — `cf deploy` hardcodes `strict: true`, and this Worker was last updated via the script API — set `strict:!1` on the deploy command in `node_modules/cf/dist/deploy-input-BAhS5LYx.mjs`, then run the same deploy. There is no CLI flag for it.
- 2026-11-06: the Cuentas and Lista de espera red bubbles vanished on those pages — SideLink sets the alert to 0 while that admin link is selected, except Empresas — keep /admin/cuentas and /admin/lista-de-espera on the same stay-visible path as Empresas.

- 2026-11-06: team alerts still landed in Hostinger spam when sent from notificaciones@ to info@ — the working Lumia pattern is the inbox writing to itself (From and To both info@) — send alerts to info@itsrelify.com from info@itsrelify.com. Leave person mail on notificaciones@.
- 2026-11-06: alerts to info@itsrelify.com still land in Hostinger spam after Gmail files the same sender under Notifications — Hostinger's MX treats mail from itsrelify.com that did not come through Hostinger SMTP as spoofed, even when SPF includes Maileroo, DKIM is at mta._domainkey, and DMARC is p=none — whitelist notificaciones@itsrelify.com on the info@ mailbox. Do not chase it in the template.
- 2026-11-06: Relify mail landed in spam while other Maileroo apps did not — the notice mails added a mailto List-Unsubscribe header, which marks the message as a mailing list — do not put that header on a one-to-one receipt. SPF already includes Maileroo and DKIM is at mta._domainkey.
- 2026-11-05: a waitlist row was saved and neither the person nor info@ got the mail — the Worker was still the 4 Nov deploy, from before those emails existed, and a saved row does not mean a mail left — deploy after a mail change and read the Worker log for `[mail]` before calling it spam.
- 2026-11-04: the seller ficha Resumen hid a negative adjusted EBITDA — `draftInvestorPreview` parsed that figure as unsigned, so the minus became 0 and the card treated 0 as unknown — parse adjusted EBITDA with the signed pattern, same as the accounts EBITDA.
- 2026-11-04: the stay dropdown opened from its title — a `label htmlFor` activates the `OptionSelect` button — use a plain heading, the same way CNAE does, so only the field opens the menu.
- 2026-11-04: the seller marketplace preview hid Ajustado on a negative adjusted EBITDA — `MarketPreview` parses that figure with the unsigned euro pattern, so a minus becomes 0 and the card treats 0 as unknown — parse it with the signed pattern, the same way the accounts EBITDA is parsed.
- 2026-11-04: sign-in as test_deale found no row in Docker — that seller and the SABI import live on itsrelify.com, and the local seed only has the itsreleva.com demo accounts — use production for that company.
- 2026-11-04: `tsc` could not find `src/app/admin/page.js` — `.next/dev/types/validator.ts` still pointed at routes from before the `(app)` group — delete `.next`, run `npx next typegen`, then typecheck. Do not edit that generated file.
- 2026-11-04: a new control copied the shadcn button or a new hex — the signed-in shell is Costa and the form controls are the indigo kit in `src/components/ui/form` — read `docs/DESIGN.md` and do not restyle one palette into the other.
- 2026-10-23: the home city glass vanished — class names were renamed Relify-* while CSS stayed .releva-* — keep the CSS prefix as releva- even when the visible brand says Relify.
- 2026-10-23: onboarding accepted a company CIF as a personal id — the person step and the company NIF are different checks — keep DNI and NIE on the person step, and the CIF checksum on Verifica tu empresa.
- 2026-10-23: a real DNI failed onboarding with the letter error — the field used the company CIF checksum — accept DNI, NIE, and CIF through isValidSpanishTaxId.
- 2026-10-23: the favorite heart stayed an outline — animateicons HeartIcon puts className on a wrapper and the svg keeps fill none — use lucide Heart and set fill on the svg.
- 2026-09-30: Shell commands failed with no exit status — the workspace directory did not exist yet, so the shell had no working directory — create the repo folder before any terminal call.
- 2026-09-30: `docker compose up` could not reach the engine — Docker Desktop was installed but not running — start Docker Desktop before Compose.
- 2026-09-30: `next dev` appended a Next.js block to `AGENTS.md` — `agentRules` defaults to true and writes that file — set `agentRules: false` in `next.config.ts` and keep the project instructions.
- 2026-09-30: `prisma.project` was undefined after a new model — `next dev` kept the global Prisma client created before `prisma generate` — restart `npm run dev` after generating the client.
- 2026-10-01: sign-in sent every role to `/cuenta` — `getSession` in that same server action does not see the cookie Better Auth just set — read the stored role from the database after `signInEmail`, then redirect.
- 2026-10-01: Vitest reported `Cannot find package '@/lib/...'` — the test runner does not apply `tsconfig` paths — import sibling modules with relative paths in any file a unit test loads.
- 2026-10-01: PrismaClientValidationError Unknown field after `prisma generate` — `next dev` kept the global client and a stale `.next` cache — stop the dev server, delete `.next`, then start it again.
- 2026-10-04: the path pointer stayed on the first card outside Cursor — a reduced-motion setting turns CSS animation off, and the Cursor browser does not use that setting — move that pointer in JavaScript, and fade the step card with a transition that the reduced-motion rule does not cancel.
- 2026-10-04: a new hero reel stayed still in the Cursor browser — that browser does match `prefers-reduced-motion`, and the reduce block sets `animation: none` — leave landing motion out of that block when it has to stay visible.
- 2026-10-04: euro figures inside a client component hydrated with a mismatch — `Intl` currency spacing differs between the server render and the browser — format euros in the server component and pass the finished strings.
- 2026-10-05: `npm install` failed with ERESOLVE on `react-server-dom-webpack` — the existing vinext and React peers already conflict — install a new package with `--legacy-peer-deps`.
- 2026-10-06: `react-hooks/set-state-in-effect` fails when an effect copies sessionStorage into state — keep a visit-only preview in component state — do not call setState inside that effect.
- 2026-10-06: `next/image` rejects a seller photo data URL — the ficha preview uses a plain `img` with one eslint exception — do not pass those bytes to `Image`.
- 2026-10-07: Cloudflare `npm clean-install` failed with ERESOLVE on `react-server-dom-webpack` — Workers Builds does not pass `--legacy-peer-deps` — keep `legacy-peer-deps=true` in `.npmrc`.
- 2026-10-07: the Worker build could not load `@/generated/prisma/client` — that client is gitignored and Cloudflare skips Prisma's install script — generate it at the start of `vite build`.
- 2026-10-07: `tsc` rejects `createAuth(): Auth` when `Auth` is `ReturnType<typeof betterAuth>` — the specific options return is not the generic Better Auth type — infer `Auth` from `ReturnType<typeof createAuth>`.
- 2026-10-07: importing Arc `foundation.css` restyles Costa — that file sets `:root` tokens the app already uses — scope them to `.arc-scope` and do not keep its global focus rules.
- 2026-10-08: renaming a demo data-room file returned "sin barras ni rutas" — seed file ids are `demo-cala-file-N`, not UUIDs — accept that id shape in `renameDataRoomFileSchema`.
- 2026-10-09: Ctrl+Z did nothing in the ficha euro fields — `groupedEuro` rewrote the input on every keystroke, and Chrome drops the undo stack when the controlled value is not the typed text — show the raw value while that field is focused.
- 2026-10-09: Better Auth logged `Invalid findFirst` while entering the platform — Postgres was stopped and the log cuts off the cause — start Docker and confirm a query answers before changing the auth adapter.
- 2026-10-12: semibold labels used another family than the body — a failed Google Fonts download left only the Arial fallback, and that face matches weight 400 — request 400, 500, 600, and 700 on DM Sans so those weights stay in the family.
- 2026-10-12: the deposit toast hydrated the company grid — `AppToast` returned null on the server because `document` was missing and a portal on the client — portal only after hydration, with `useSyncExternalStore`. A button inside a heading does the same: the browser lifts it out, so a hint inside an `h2` stays a focusable span.
- 2026-10-15: the Worker threw `Wasm code generation disallowed by embedder` on every Prisma query — the Node client compiles the query compiler at runtime — generate a second client with `runtime = "cloudflare"` and alias it only in the vinext build.
- 2026-10-15: deployed sign-in returned `e is not a function` — the workerd export of `@better-auth/utils/password` calls `node:crypto` scrypt, and `toNextJsHandler` calls the auth proxy when `"handler" in auth` is false — alias the noble password build in vite, and add a `has` trap on the auth proxy.
- 2026-10-18: sign-in showed Invalid user.findUnique and the overlay cut the cause — Postgres was stopped (ECONNREFUSED) — start Docker before changing the query, and keep that lookup inside the sign-in try so a down database returns the Spanish failure.
- 2026-10-18: Avisos threw "Cannot call startTransition while rendering" — `markAllRead` ran inside the `setOpen` updater — call `startTransition` from the click handler, not from a state updater.
- 2026-10-15: the seller home was canceled as a hung Worker after sign-in — one `Promise.all` opened more Postgres sockets than Workers will finish — load that page one query after another.
- 2026-10-21: `/mi-empresa/documentos` looked like an empty file — Tailwind `flex`/`fixed` on a closed `<dialog>` overrode `display: none` — use `hidden open:flex` (or only mount the dialog when open).
- 2026-10-22: production sign-in showed “No se ha podido entrar” with valid demo passwords — Neon production lacked `terms_accepted_at` and `signature_png` on `user` (and `sale_reason` on `project`) while the Worker Prisma client expected them — run pending `prisma migrate deploy` against the production branch after each schema change.
- 2026-10-22: accepting the platform agreement returned 500 on itsrelify.com — `acceptPlatformTermsAction` wrote under `data/platform-signatures` before updating Postgres — Workers have no writable disk — store `signaturePng` in the database only.
- 2026-10-22: investor premium checkout showed “No se ha podido abrir el pago” — `billing_customer.stripe_customer_id` was the seed placeholder `demo_cus_comprador`, not a real `cus_` id — replace invalid ids when opening Checkout, and set `STRIPE_SECRET_KEY` on the Worker for test mode.
